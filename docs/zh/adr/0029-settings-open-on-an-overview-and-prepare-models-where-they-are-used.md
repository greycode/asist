# 设置从概要打开，模型的准备在使用该模型的那一行做

设置界面从“概要”打开。概要里列出语音识别、对话模型、朗读当前的构成，还有已设为使用却还没有运行的，以及仍处于关闭状态就能添加的功能。模型和运行环境的获取，不另做一个只收集准备的页面，就在选择或打开该模型的那一行做。语音识别在“声”的语音识别那一行准备，语义检索在“記憶”的语义检索那一行准备。左侧列表和概要发出警告的，只有已设为使用、却不运行的，关闭中的功能不计入。选择的地方和准备的地方分开，就要在页面之间来回跑。连关闭的功能都算作“未準備”，那什么也不做，警告也不会消失。

唯一的例外是：因更新而需要准备声音模型时，启动时通知的按钮会从设置之外开始准备（ADR 0058）。

## 未采纳的方案

- **把准备集中到“模型”页面。** 以前的形式。语音识别在“声”里选择、在“模型”里获取，选择的地方和准备的地方分开，靠“「モデル」を開く”的链接来回跑了很多次。
- **不设概要，从“会話”页面打开。** 页面的划分方式一样，但要看当前的构成和缺什么，就得一个一个地打开页面。
- **把所有页面排在一张上，用搜索缩小范围。** 页面会变得非常长。搜索会连许可清单这类与设置无关的行都翻出来。
