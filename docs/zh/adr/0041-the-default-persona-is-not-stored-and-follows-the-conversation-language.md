# 角色为默认值时，不保存文本，按对话语言读取

设置里的“キャラクター”是默认值时，settings.json 里不写文本，只保存它是默认的这一状态。对话的提示词、设置界面、记忆的整理每次读取时，都按当时对话的语言取出默认文本（`personaText`）。用户写下的文本原样保存，改变对话语言也不改动。因为把默认文本原样存进设置的话，每次改变对话语言都得改写那段文本，而从不会改写的界面改变语言的人，就会继续用前一种语言的角色说话。采用这种形式，修改默认文本时，也会原样送到所有没有自己写过文本的人那里。

## 未采纳的方案

- **把默认文本保存下来，改变对话语言时如果与默认相同就改写。** 每个改变语言的地方都需要改写，只要漏掉 1 处，前一种语言的角色就会残留。而且，是否属于默认要靠比较文本来判断，所以修改默认文本后，此前的默认文本会被当成用户写的东西。
