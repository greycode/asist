# 首次设置只准备 MaAI，是否打开交给用户

用日语语音对话的用户，首次设置会获取并准备好 MaAI 的模型，但轮流发言的设置保持关闭。想用的人在“声”界面把它打开。MaAI 在对话期间会一直在 CPU 上运行，所以在 Apple M2 这样的机器上会和 Qwen3-TTS 争抢 CPU，朗读的声音会中断。没有 MaAI 也能对话，但声音中断会让对话难以听清。只要提前把准备工作做完，打开开关就能用，所以 245MB 的获取放在首次设置里做完。

## 未采纳的方案

- **首次设置也不做准备。** 等想用的时候，就得在设置的“声”里等待获取。
- **只在快的机器上打开。** 哪些机器不会发生争抢，需要实测后划出一条界线。

## 实测

2026-09-28，在 M2 16GB 的 Mac 上单独运行 Qwen3-TTS 时，生成 1 秒的语音要花 0.53～0.54 秒，播放没有中断。在应用里和 MaAI 一起运行时，MaAI 处理速度的比值升到 1.27～1.55，朗读出现中断。关掉 MaAI 后不再中断。

## 已知限制

- 不会改动已经打开 MaAI 的用户的设置。
