# 关闭窗口和最小化时关掉麦克风，窗口恢复后麦克风仍保持关闭

把窗口关闭、收进 Mac 的菜单栏或 Windows 的通知区域时，以及最小化到 Dock 或任务栏时，关掉麦克风。麦克风一关，语音识别、MaAI、附和种类的判定会立刻停止，朗读的模型也会在说到一半的回应结束后的 watchdog 确认中停止，因此隐藏起来的应用不会继续占用内存和 GPU 内存。隐藏起来的应用也不会继续拾取房间里的声音。窗口恢复后麦克风仍保持关闭，只有用快捷键唤起时才像以往一样打开麦克风。这是为了在用户只是为了看卡片而恢复窗口时，麦克风不会自己打开。窗口隐藏期间结束的任务通过 OS 通知当场告知，用声音做的报告则等到窗口恢复。因为麦克风关着，听了报告也答不上话。

## 未采纳的方案

- **收进托盘后仍保持麦克风打开。** 这样能从托盘说话，但要么让模型一直驻留，要么每次 VAD 捕捉到开始说话都重新加载，连房间里的说话声和电视声也会触发重新加载。
- **窗口恢复后回到隐藏前的麦克风状态。** 仅仅为了看卡片而恢复窗口时，麦克风也会打开。
- **把最小化与托盘分开处理，保持麦克风打开。** 在 Windows 上常用最小化来收起窗口，其间 VRAM 不会释放。
- **窗口隐藏时也用朗读当场报告已结束的任务。** 即使重新加载朗读的模型、用声音告知，麦克风关着也答不上话。

## 已知限制

- 收进托盘的状态下，不能再用声音搭话。
- 只是被其他窗口挡在后面时，不关掉麦克风。只靠窗口事件来区分关闭时和最小化时。
