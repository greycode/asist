# 自己的邮件地址只限于账号的地址与设置里写的地址，不从已发送的邮件推测

每个邮件账号在设置里放一栏“ほかに送信に使っているアドレス”，只把账号的地址与写在那里的地址当作自己的地址（`isOwnAddress`）。对自己发出的邮件的回复收件人、“全員に返信”中从收件人里去掉的地址、告诉对话模型的自己的地址，全部由此决定。该栏为空的账号，只有账号的地址是自己的地址。像 Gmail 的发件地址那样，用户有时会从与账号地址不同的地址发送，但 ASIST 没有从邮件确认哪个是自己的地址的手段，所以请用户填写。

## 未采纳的方案

- **把已发送文件夹里邮件的发件人全部当作自己的地址。** 如果有代上司发出的、用上司地址发送的邮件，上司就会被当作自己，回复那封邮件时上司会从收件人中消失。

## 已知限制

- 这里写的地址只用于辨认自己的地址。新邮件和回复的发件人始终是账号的地址，不能从这里写的地址发送。这一点也告知了对话模型。
