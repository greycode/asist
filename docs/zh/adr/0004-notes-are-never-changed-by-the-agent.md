# 把笔记当作用户的文档，对话中的 Agent 只能新建和阅读

每条笔记做成 1 个 Markdown 文件，放在 `userData/notes/` 里。对话中的 Agent 能用的工具只有写新笔记的 `add_note`、查找的 `search_notes`、阅读的 `read_note`，既不能改写已有的笔记，也不能删除。改写和删除都在笔记的界面上操作，删除则是在确认之后把文件移到 macOS 的废纸篓。

记忆由整理 Agent 写入并附在对话里，而笔记是用户自己写下并留存的文档，内容不能在用户不知道的情况下发生变化。出于同样的理由，笔记不放进每次对话，而是在需要的时候用工具阅读。

## 未采纳的方案

- **Agent 在已有笔记末尾追加内容的工具（`append_note`）。** 即使做成不允许整体覆盖的形式，也仍然是 Agent 改动用户的文档，所以不加入。
- **从对话中删除笔记的工具。** 与记忆一样，删除在界面上做就够。
- **把笔记作为记忆的一部分。** 记忆由整理 Agent 改写，不适合作为用户文档的存放之处。
