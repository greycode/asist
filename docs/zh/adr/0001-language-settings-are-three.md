# 语言设置分成界面语言、对话语言和地区 3 个

界面语言决定界面上出现的文字和错误，对话语言决定说话的语言、听辨的语言、提示词和写记忆所用的语言，地区决定天气与新闻的来源、默认货币、日期和数字的写法。这 3 个可以分别更改，在应用运行中更改也会从下一轮开始生效。这样安排，是为了让住在日本却说英语的人保持界面和对话为英语，同时能看日本气象厅的天气。首次设置只询问一种语言，并把它作为这 3 个的初始值。因为一开始就分别询问这 3 个，对大多数人来说只会是些不明白含义的问题。

即使中途更改对话语言，此前的记忆和历史仍按写入时的语言保留。记忆检索只用一个多语言模型，是为了能直接检索语言混杂的记忆。天气在地区为日本时取自日本气象厅，其他地区取自 Open-Meteo。

## 未采纳的方案

- **把语言合并成一个。** 上述用法就无法实现。
- **日期和数字的格式直接使用界面语言。** 英语界面必然变成 12 小时制，住在德国的人用英语界面时就写不出“18:05”“22/09/2026”。格式要由界面语言结合地区的习惯来决定。

## 已知限制

- 格式数据（CLDR）中没有“日本的英语”这类组合时，格式不遵循地区，写法只由语言决定。
- 没有加入从右到左书写的语言，所以也没有把界面左右翻转的做法。
